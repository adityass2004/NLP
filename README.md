# Natural Language Processing

This repository contains practical implementations for the **Natural Language Processing (NLP)** course, organized unit-wise.

---

## Units

### Unit 1 – NLP Fundamentals

Core NLP techniques implemented using Python and NLTK.

| Notebook | Topic |
|---|---|
| `Regular_Expression.ipynb` | Pattern matching using regex |
| `TF-IDF_Word_Level_Analysis.ipynb` | Term frequency-inverse document frequency |
| `N-grams.ipynb` | N-gram language modeling |

### Unit 5 – NLP Applications

Advanced NLP applications built using pretrained transformer models.

| Notebook | Topic |
|---|---|
| `Chatbot_Experiment.ipynb` | Conversational AI with pretrained LLM |
| `Question_Answering_System.ipynb` | Context-based answer extraction |
| `Text_Summarization.ipynb` | Abstractive text summarization |
| `Machine_Translation.ipynb` | English to French translation (Seq2Seq) |
